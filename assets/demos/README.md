# AR5 双臂协同上枪头演示

2026-11-20，当前视频：`robot_dual_arm_camera_pickup.mp4`，12 秒，1920×720，25 fps，无音频。左右两部分逐帧同步，每部分 960×720：左侧为第三视角，右侧为左法兰相机。

左臂在右臂对准、套接和提起时配合移动。相机固定在左法兰，POV 由机器人正向运动学和固定安装变换计算。`left_flange_camera.glb` 是程序生成的示意外壳；垂直视场 60°、光心距法兰 60 mm，尚未用真实相机型号和标定数据确认。相机位姿及安装参数随场景 JSON 保存。网页回放可选择第三视角或左法兰相机，下载视频为同步双视角。

新轨迹 `dual_arm_camera_pickup.json` 保留原有右臂与躯干轨迹，新增左臂 7 个关节。301 帧左右工具/光心变换通过独立 Three.js FK 核对，关节角与速度满足 URDF 限制；两种网页回放模式的枪头随动、光心跟随和结束恢复通过自动测试。详细参数见 `dual_arm_camera_pickup.audit.json`。

- 机器人：Wheel_Robot_PD2616-2.0 -AR5，保留原 URDF 关节与限位。
- 移液枪：`pipette_stand_metal_tip.glb`，绿色圆盘维持右法兰固定耦合。
- 枪头盒：用户 `枪头盒_补充细节_凸台6.5mm.blend`（11月14日），导出 `tipbox_detail_6p5mm.glb`，原始米制比例、96 个黑色枪头与滤芯、黄色凸台和白色盒身保留。
- 孔位 A12；几何下压 3 mm，随后的竖直提起 150 mm。8 秒时将该枪头及其滤芯固定到移液枪局部坐标，其他枪头保留在盒中。
- 301 个关节姿态按工具位姿求解，角度及帧间速度均满足 URDF 限制。浏览器以这些关节姿态连续回放；演示独立临时分组，不改写用户编辑对象，完成后恢复相机、玻璃窗及控制开关。
- 同一套模型、变换和姿态与场景一去噪高斯 `environment_clean_v2.sog` 一起离线渲染。按 SOG v2 解码位置、透明度、协方差和三阶球谐颜色，按相机投影绘制高斯，并用每像素网格深度处理前后遮挡；全景显示原扫描桌椅、立柱、窗帘等环境。双视角使用统一世界坐标；移动相机每帧重投影高斯并按相同光心和内参合成网格，网页回放使用相同的光学位姿。
- 每 5 帧进行一次已有近似碰撞引擎的机器人/柜体/扫描结构检查，未发现交叠。接触目标单独处理；连杆包围体并非完整接触力学验证。邻近枪头的包围体可能保守重叠，不能将视频当作实机可执行程序。
- 环境 ×1.462 为试用比例；移液枪 250 mm 为展示长度，尚未实测标定接口。插入力、摩擦、弹性、真实配合、重力与抓取不在本演示范围内。
