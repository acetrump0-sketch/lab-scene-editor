# 增强去噪与近似碰撞层（2026-11-20）

入口：`studio/index.html`。默认开启增强去噪与防穿透；左侧取消增强去噪可查看原扫描，右侧可显示碰撞边界并选择结构定位。

## 去噪

- 场景一原扫描 1,000,000 点中隐藏 20,325 个候选（2.03%）；替换实验柜后的背景新增隐藏 20,314 点，其余 11 点原已隐藏。
- 场景二 674,162 点中隐藏 14,136 个候选（2.10%）。
- 依据低透明度与局部稀疏度、异常体积联合筛选，避免仅凭低透明度删除玻璃和薄壁。不是语义分类，仍可能误删或留下密集重影。
- 输出新 SOG，只修改 `sh0.webp` 的候选 alpha；原 SOG 保留。验证其他 ZIP 成员、RGB 代码与保留点 alpha 不变。具体计数、源 SHA-256 见 `cleanup_audit_v2.json`。
- 可用 `python tools/build_environment_v2.py --decoded-root /path/to/cache` 重建，需要 NumPy、SciPy、Pillow；缓存含 `scene1_denoise/decoded.npz` 和 `scene2_denoise/decoded.npz`，字段为 p、alpha、rgb、scales、d（第八近邻距离）。缓存属于原扫描解码产物，未重复纳入仓库。

## 碰撞覆盖

- 场景一：53 组轴对齐平面候选、1,209 个有扫描支持的矩形片。保留采样空隙，不将整组包围盒填满。墙壁/立面、台面/水平面、顶面参与近似检查。扫描地面有高度噪声，地面接触统一采用世界 Y=0；地面候选仅显示供核对。
- 实验柜：静态网格三角面 BVH，玻璃窗使用实时变换后的三角面；窗升降也执行分步检查。
- 机器人：各可视网格按 URDF 连杆归属建立定向包围体，右臂移液枪逐部件参与。检查机械臂与非相邻连杆、器材和环境；连接邻居与躯干内部装配重叠排除。不是完整全机自碰撞模型。非均匀缩放产生剪切时保守退回轴对齐包围体。
- 独立器材：原有器材间包围体检测、盒架/枪头关联保留，并检查环境、柜体与机器人。
- 平移按 2 mm、根旋转按 0.04 rad、关节按 0.005 rad 采样，发现碰撞撤回本次操作。关节单次超过约 114°、根移动超过 600 个步长时要求分段。
- 仅作交互式运动学约束：不计算重力、接触力、液体或抓取，采样间窄障碍可能漏检，包围体可能保守误报。柜体使用表面相交，已完全嵌入实体内部的导入姿态不保证被识别。
- 背景调整同步变换扫描碰撞片；切换场景清空旧碰撞片。场景二只增加去噪，尚无扫描结构碰撞层。
- 1.462 倍为用户试用比例，未实测标定。并未把所有扫描器材自动恢复为独立 mesh。
- 防穿透与边界显示状态随场景 JSON 保存；RGB 导出临时隐藏碰撞提示和边界。

## 验证

运行 `node --experimental-loader ./tests/three-loader.mjs tests/environment-collision.mjs`：实际机器人/工具/柜体 GLB 初始姿态、毫米网格缩放、有效关节运动、工具碰撞回退、禁用防穿透、路径穿墙、背景变换同步、场景清空、地面与非相邻机械臂自碰撞。

另已回归原机器人关节限位、JSON 姿态恢复、右臂绿色接口耦合、7 轴随动与左右臂独立性。典型默认机器人检查约 15–31 ms，柜体 BVH 构建约 0.7–1.3 s（本机 Node 离线测试，浏览器耗时可能不同）。清理前后检查采用点中心投影和文件一致性校验，并非完整高斯渲染目测验收。本轮本地浏览器预览访问被拒，未完成交互式浏览器验收。
