# 实验室仿真编辑器 V16

[打开编辑器](studio/index.html)。建议使用支持 WebGL2 的桌面浏览器，首次加载需要下载环境与模型。

- 左键环绕，右键平移，滚轮缩放。
- 点击器材或左侧列表选中，拖动坐标轴；W/E/R 切换移动、旋转、缩放。
- Shift + 拖动物体在所选平面移动；盒内枪头需先取出。
- 支持加入、复制、移除器材，场景 JSON 保存和读取。
- 原工位及 96 个独立枪头保留；扫描环境经粗配准接入原工位坐标。

周边桌子、货架仍是 3DGS 背景，不能逐件拖动。原始扫描对照会临时隐藏网格模型。编辑背景将扫描柜体区域透明化，避免双重柜体，原始资源另行保留。配准属于粗轮廓拟合，扫描未做米制精确校准，没有新增环境碰撞网格，不能直接用于机器人定位。

目录仅包含仿真运行资源与说明，没有训练数据、模型权重、实验报告或训练评估脚本。共享模型与编辑器控件来自仓库 assets/ 与 vendor/，V16 渲染依赖在本目录 vendor/。所有资源为相对地址，可从仓库根目录运行 HTTP 服务预览。

第三方组件：Three.js 0.180.0（MIT）、Spark 2.4.0（MIT）；许可证见 vendor/。
