# 实验室仿真编辑器 V16

[打开编辑器](studio/index.html)。建议使用支持 WebGL2 的桌面浏览器，首次加载需要下载环境与模型。

- 左键环绕，右键平移，滚轮缩放。
- 点击器材或左侧列表选中，拖动坐标轴；W/E/R 切换移动、旋转、缩放。
- Shift + 拖动物体在所选平面移动；盒内枪头需先取出。
- 支持加入、复制、移除器材，场景 JSON 保存和读取。
- 原工位及 96 个独立枪头保留；扫描环境经粗配准接入原工位坐标。

周边桌子、货架仍是 3DGS 背景，不能逐件拖动。原始扫描对照会临时隐藏网格模型。编辑背景将扫描柜体区域透明化，避免双重柜体，原始资源另行保留。配准属于粗轮廓拟合，扫描未做米制精确校准，没有新增环境碰撞网格，不能直接用于机器人定位。

目录仅包含仿真运行资源与说明，没有训练数据、模型权重、实验报告或训练评估脚本。共享模型与编辑器控件来自仓库 assets/ 与 vendor/，V16 渲染依赖在本目录 vendor/。所有资源为相对地址，可从仓库根目录运行 HTTP 服务预览。

第三方组件：Three.js 0.180.0（MIT）、Spark 2.4.0（MIT）；许可证见 vendor/。

默认工位已换成用户提供的绿色支架/金属末端移液枪，可从“最新重建”菜单重复加入。原 P1000 仍可选。GLB 保留 18 个部件及原材质，原始 Blender 文件位于 assets/source/。原文件无标定单位，统一展示高度暂设 250 mm，不代表实测尺寸。

## 2026-11-17 第二高斯场景

左侧“环境场景”可切换：

- 场景一：原安全橱实验室，沿用原扫描和粗配准。
- 场景二：新 Insta360 扫描，包含前厅、走廊等实景，提供 1,890 个原始扫描机位。

场景二首次进入默认“只看原始扫描”，保留原扫描的相对几何，不将旧柜体叠在走廊中。点击“返回工位编辑”或取消“只看原始扫描”可显示并操作已有独立器材。两场景共用同一套可编辑工位资产，切换不会自动改变器材的位置。周边扫描物体仍是高斯背景，不能逐件拖动。

“调整扫描背景位置”提供 X/Y/Z 平移、朝向与缩放，仅修改当前背景。两个场景分别记忆视角与背景调整。保存的场景 JSON 记录当前场景、背景变换和器材摆放；读取旧 V16 文件仍默认原场景。渲染标注也包含环境标识及扫描到工位的变换。

场景二的初始摆放以首个扫描相机为基准，只用于浏览和编辑，没有与旧安全橱进行实测配准，也未做米制尺度标定；不能直接用作机器人外参。新环境未增加碰撞网格。

新场景来源与文件校验见 [scenes/scene2/source.json](scenes/scene2/source.json)，场景配置见 [scenes.json](scenes.json)。资源已保存为本站相对路径，不依赖会过期的临时下载链接。

## 六自由度自由探索

顶部「进入自由探索」启用飞行相机，保留原有器材编辑模式。W/S 前后，A/D 左右，空格/C 升降，均沿相机局部坐标；Q/E 绕视线滚转，方向键俯仰/偏航，Shift 四倍加速。按住画面拖动转向，或点击「锁定鼠标看向」使用第一人称鼠标控制；Esc 返回编辑。可调整速度，并在相机面板输入世界 X/Y/Z、Pitch/Yaw/Roll（度，YXZ 欧拉顺序，零角度朝 −Z）。飞行使用四元数增量旋转，支持翻转，不受地面或碰撞限制。

场景 JSON 保存相机四元数、up 和探索模式，兼容旧文件。探索期间不会用 WASD/QE 触发器材变换。扫描环境尚无米制标定，因此移动速度与位置按引擎单位解释。
