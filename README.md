# 实验室场景编辑器

基于 Three.js 的实验室器材布局、相机取景与数据集导出工具。

## 最新版本 V16

[在线打开可编辑仿真环境](https://acetrump0-sketch.github.io/lab-scene-editor/v16/studio/index.html) · [版本说明](v16/README.md)

保留独立器材编辑与自由视角，并接入配准的实验室扫描背景。

## 使用

打开 GitHub Pages 网站即可使用。建议使用支持 WebGL 且开启硬件加速的桌面浏览器。首次加载需下载三维模型。

操作、尺寸依据和数据格式见 [使用说明](instruction.md)。所有场景编辑和渲染在浏览器本地运行；保存和导出文件下载到访问者电脑。

## 本地预览

```sh
python3 -m http.server 8000
```

浏览器访问 http://localhost:8000/ 。

## 部署

GitHub Pages 使用 main 分支根目录发布。资源使用相对路径，支持项目子路径。

## 第三方组件

Three.js 与 fflate 的许可证位于 vendor/。模型尺寸中除说明的实测项目外包含展示假设，渲染结果不代表物理仿真或测量精度。


## 新增资产库（2026-11-05）

已接入力辰 P1000 R3 八部件白模，默认出现在场景中。展示总长暂定 250 mm，不代表实测；未添加新贴图。

附带 CAD 包含 32 种资产、66 个版本，每种取最高版本，校验 STL 的 SHA256 后转换为 GLB。新增模型按需加载，保留源几何；STL 无单位，依据数值范围暂按米解释、沿用源坐标，尚未核对实物。特别是 1000 μL 枪头尺寸偏小，不能用来推定配套尺寸。原始 STEP 声明毫米，与 STL 是不同导出格式，未直接套用到 STL。

器材菜单按来源分组，选中后显示接口与槽位描述，支持聚焦查看。接口字段仅作说明，不执行吸附、装配、碰撞或机器人运动。CAD 模型没有源贴图，灰色材质仅用于展示；机械装配合并网格不提供关节动画。CAD 移液器装配与力辰 P1000 为两个独立资产。新增来源、版本、接口与尺寸依据随场景和标注导出。

资产明细见 [asset-inventory.json](asset-inventory.json)。大型 CAD 工位默认也从台面加入，请通过位置/旋转调整，避免与现有柜体重叠。
