# 随机仿真数据与口沿中心识别实验

日期：2026-11-09。目标：从RGB图识别枪头口沿中心和蓝色枪口端面中心，计算Δu=u枪口−u枪头、Δv=v枪口−v枪头，像素坐标向右/向下为正。

## 数据

2,000张1280×960图片，1,000个随机场景，每场景两视角。训练/验证/测试为1,600/200/200张，按场景隔离。已验证2,000张图片哈希各异、场景无交叉。图片无文字标注，包含几何中心、实例ID、相机及可见性代理标签。

随机改变主光、补光、曝光、枪头基础alpha（0.12–0.52，越高越不透明）、粗糙度、外壳alpha、盒位置和旋转、枪口间距（6–45mm）、占用孔位、视角和距离。相机俯仰约−2°到22°。基线模型和背景仍相同。原始数据归档SHA256：`43ee528813154050fef105ca6d14183040e977a9bb2668f175fa9c26e6f77a90`。

## 1,600张训练图结果

使用YOLO26n-pose，两类别、每实例一个口部关键点。上限50轮，最佳权重仅依据验证集选择。测试200张，所有误差均换算至原始1280×960图像。

| 指标 | 结果 |
|---|---:|
| 可评估配对 | 6,178 |
| 成功配对 | 4,459（72.18%） |
| Δu平均绝对误差，仅成功配对 | 1.68px |
| Δv平均绝对误差，仅成功配对 | 1.52px |
| Δ向量误差中位数 / P90，仅成功配对 | 1.99 / 4.89px |
| 5px内成功率，含漏检 | 65.26% |
| 最近三维枪头配对5px内成功率 | 86.90%（145个符合条件的帧） |

5px成功率在近水平视角（<5°）为45.59%，较高视角为74.18%；密集占用为50.09%，稀疏占用为83.67%。这些组同时存在其他参数变化，不能视作单因素因果实验。主要不足是密集、近水平场景中的枪头漏检。

## 解释与限制

这说明现有仿真环境能批量产生训练数据，并训练出像素定位模型；不说明任意枪头都已可靠识别。需要进一步补充密集和平视困难场景，并用独立真实照片验证。透明度和光照仍是经验材质近似，不是物理光学标定。

可见性通过不透明实例代理渲染判定，口沿16个采样点至少25%可见才监督中心；并非透明件真实光学可见性。测试以GT框作同类别匈牙利匹配（IoU≥0.3），这是离线评分，不代表部署时已经解决A01–H12孔位身份。被遮挡枪头不能保证从单张图恢复。二维Δ像素也不直接等于毫米偏差。

原服务器YOLO模型只训练了tip_rack/well_plate_96，先前8张基线图没有有效枪头/枪口配对；SAM分割置信度不能证明语义正确。因此本次训练专用口部关键点模型。

## 400张与1,600张训练图对照

两次实验使用相同验证/测试场景、预训练起点、随机种子和最大训练轮数。更多图片也意味着每轮更多优化步骤，所以这是实际训练方案对照，不是计算量相等的因果实验；目前只运行一个种子。

| 指标 | 400张 | 1,600张 |
|---|---:|---:|
| 配对覆盖率 | 75.04% | 72.18% |
| 5px内成功率，包含漏检 | 58.42% | 65.26% |
| Δ向量误差中位数，仅成功配对 | 2.85px | 1.99px |
| Δ向量误差P90，仅成功配对 | 7.44px | 4.89px |
| Δu平均绝对误差，仅成功配对 | 2.54px | 1.68px |
| Δv平均绝对误差，仅成功配对 | 2.06px | 1.52px |

增加数据后定位精度提高，但配对覆盖率略降。目前不能认定数量已充分，下一批应增加近水平、密集、遮挡困难场景，并保留新的独立测试集及实拍测试集，避免反复针对当前测试集调参。
